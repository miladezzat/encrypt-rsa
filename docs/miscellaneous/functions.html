splitIntoChunks
splitIntoChunks(text: string, chunkSize: number)

Splits a string into chunks for encryption. RSA can only encrypt data smaller than the key modulus minus padding. For RSA-OAEP with SHA-1 and a 2048-bit key, this is 214 bytes.

Parameters :
Name Type Optional Default value Description
text string No
  • The text to split into chunks.
chunkSize number No 214
  • The size of each chunk in bytes (default 214 for 2048-bit RSA-OAEP/SHA-1).
Returns : string[]

Array of text chunks.
